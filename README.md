FinEdu AI

  Sistema de educação e controle financeiro.

Objetivo

  O FinEdu AI tem como objetivo auxiliar usuários no controle
das suas finanças pessoais e na educação financeira.

Protótipos

  Este repositório contém os protótipos desenvolvidos para a
disciplina de APS.

 Funcionalidades

- Controle financeiro
- Educação financeira
- Simulador de investimentos
- Metas financeiras
- Perfil do usuário
